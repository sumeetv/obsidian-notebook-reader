# Obsidian Notebook Reader

An iPad-first reading experience for browsing an Obsidian vault like a physical notebook.

The selected direction is **Thumb-edge Notebook**, with **Indexed Folio** as an optional index. The reader has equal-width facing pages, independent scrolling, title previews while gliding along the page edge, and held places for swapping and comparing notes.

This project currently contains design artifacts; implementation has not started. Page Atlas is an earlier exploration and is excluded from the selected direction.
