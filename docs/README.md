# Design artifacts

## Current direction

[notebook-direction.md](notebook-direction.md) is the authoritative design brief. It includes the latest requirements: equal-width facing pages, independent page scrolling, preserved scroll positions, gliding title previews, folder sections and exclusions, held-place swapping, and an optional Folio index.

[Latest open-book mock](imagegen/thumb-edge-open-book.png) illustrates the two-page view and gliding title preview. The brief also records the equal-width and independent-scroll refinements made after this image was generated.

## Earlier explorations

[page-atlas-direction.md](page-atlas-direction.md) is explicitly superseded. Page Atlas, Two-place Desk as a standalone direction, and Wandering Notebook were explored but are not the selected primary experience. Their images remain for reference.

[notebook-preview.html](notebook-preview.html) is the standalone preview of the original five-direction exploration; [notebook-directions.html](notebook-directions.html) is its inline source. These use demo notes and precede the latest design refinements. They are not connected to an Obsidian vault.
