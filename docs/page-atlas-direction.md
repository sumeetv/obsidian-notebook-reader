# Page Atlas direction

Superseded by the user's corrected selection. Page Atlas is excluded. See [the selected notebook direction](notebook-direction.md): Thumb-edge Notebook primary, Indexed Folio secondary. The material below is retained only as an earlier exploration.

Selected direction: Page Atlas is the primary experience; Indexed Folio is an optional navigation panel in the reader.

- Open on rendered page previews grouped by folders, with A–Z ordering by default. Offer chronological ordering within each folder. Remember excluded folders, including the choice to hide or include daily notes.
- Short notes occupy one page. Long notes continue across adjacent pages bearing the same title and a continuation number. Use natural paragraph and heading boundaries where possible; avoid splitting images and code blocks.
- Tap a page to read it. Back to Atlas restores the same grid position, selected tile, filters, and ordering.
- Swipe or use previous/next to advance through the generated sequence. Crossing a folder boundary shows the next section divider.
- Show separate current and held markers in the atlas and index. Hold here anchors a passage; browsing does not replace it. Swap exchanges both locations so repeated tapping toggles predictably.
- Anchor held locations to the note and passage, rather than relying on a page number that may change with screen size or type size.
- Compare opens current and held passages together. On narrow portrait layouts, allow alternating them without losing either position.
- The optional Folio index uses the same folder sequence and exclusions as the atlas. Opening it does not reset reading or overview position.
- Exclusion changes affect browsing, not source notes. If an excluded folder contains a held note, preserve the held reference and identify that it sits outside the current browsing set.

Next validation: whether rendered page previews support recognition and rapid browsing on an actual iPad-sized surface, especially for long notes and large folders. This concept is not yet connected to a vault.
